# LeetCode DSA

A personal collection of my LeetCode solutions in C++. I'm using this repository to practise Data Structures and Algorithms, strengthen my problem-solving skills, and prepare for coding interviews.

The focus isn't only on getting an accepted solution. I also want to understand why an approach works, analyse its complexity, and compare different ways to solve a problem.

## 📂 Repository Structure

Each problem has its own folder named after its LeetCode problem number. When I explore multiple approaches, I keep them in separate `.cpp` files.

## 📈 My Approach to Problem Solving

- **Understand the problem:** Identify the requirements, constraints, and edge cases.
- **Explore approaches:** Start with a straightforward solution and look for possible optimisations.
- **Analyse complexity:** Evaluate time and auxiliary space complexity.
- **Write clean code:** Aim for readable and maintainable solutions.
- **Learn continuously:** Revisit problems and improve my understanding of algorithms and problem-solving patterns.

## 🎯 Goal

I'm building this repository as a practical record of my DSA journey.

The goal is not simply to increase the number of problems solved, but to develop a deeper understanding of data structures, algorithms, and problem-solving patterns.

I want to become better at recognising patterns, evaluating trade-offs, and choosing efficient solutions—not just writing code that works.

This repository is a work in progress and will continue to grow as I solve more problems and learn new concepts.
